# wechatagent

本地优先的个人微信沟通记忆库：归档电脑端已同步的聊天数据，支持原文可追溯搜索、每日摘要、客户画像、知识卡和 Obsidian 导出。

## 当前状态

- 产品阶段：PRD 与 UI Demo 设计
- MVP 平台：Windows 桌面端
- 数据范围：用户本人电脑端微信已经同步到本机的数据
- 同步规则：启动时补同步，运行期间默认每 5 分钟增量同步，每天 22:00 生成整理结果

## 重要边界

个人微信没有面向普通第三方的稳定全量历史 API。数据采集层必须作为可替换适配器存在；产品不承诺获取手机端每一条消息，也不承诺永久兼容所有微信版本。
