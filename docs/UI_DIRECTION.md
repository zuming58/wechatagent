# UI Demo 视觉方向定稿

> 状态：已确认，已进入正式开发；UI Demo 已完成第一轮实现与视觉验收。  
> 定稿日期：2026-07-23  
> 唯一视觉基准：`prototypes/ui-demo/reference/relationship-workbench-final-bright-blue.png`

## 1. 设计结论

采用“明亮蓝色工作台”方向：左侧为很浅的中性灰导航，最左保留细亮蓝品牌竖条；当前导航、主要按钮、活动标签、链接和选中标记使用亮蓝。联系人栏保持冷白/极浅天蓝，右侧关系工作区保持大面积纯白。

设计感来自布局、留白、细分隔线和字体层级，不使用渐变、厚重阴影或大面积卡片。明确拒绝整面深海军蓝左栏、低饱和灰蓝/雾蓝、土灰色主题，以及把全部状态都染成蓝色。

## 2. 颜色规范

| 用途 | 色值 | 使用范围 |
| --- | --- | --- |
| 品牌亮蓝 | `#1677FF` | 主按钮、当前导航、活动标签、链接、选中标记 |
| 亮蓝悬停 | `#0B6BEB` | 可点击亮蓝元素悬停 |
| 浅蓝选中底 | `#EAF3FF` | 联系人选中、搜索聚焦、AI 建议区域 |
| 左栏浅灰 | `#F5F6F8` | 主导航底色 |
| 联系人栏底色 | `#F8FBFF` | 联系人列表 |
| 主内容底色 | `#FFFFFF` | 关系详情和时间线 |
| 文字主色 | `#172033` | 标题与正文 |
| 次级文字 | `#667085` | 时间、说明、辅助信息 |
| 细分隔线 | `#E6EAF0` | 列表、栏目、标签页 |
| 成功绿 | `#12A150` | 已确认事实、同步成功 |
| 提醒黄 | `#FFF8E8` | 需求与关注事项 |
| 待办紫 | `#F7F3FF` | 待办事项模块 |

禁止使用渐变。绿色只表达确认或同步成功，不承担品牌色职责。

## 3. 页面结构

桌面端固定为三栏：

1. **主导航栏**：约 216px，浅灰底、6px 亮蓝品牌线，包含关系记忆、待办、搜索、时间线、标签、设置和回收站。
2. **联系人栏**：约 306px，顶部搜索，列表使用细分隔线；当前联系人使用浅蓝底和左侧亮蓝短线。
3. **关系工作区**：剩余宽度，大面积白色；顶部显示联系人身份和主要操作，下方为总览、聊天证据、待办、标签与备注。

总览首屏两列：左列为已确认事实、AI 建议、当前需求与关注；右列为待办和聊天证据时间线。

## 4. 头像规则

- 有可用微信头像时显示最新同步到本地缓存的头像。
- 无头像时显示姓名首字，使用亮蓝或低饱和蓝色圆形底。
- 联系人身份使用“账号标识 + 微信稳定内部标识”，不以头像、昵称或实名作为主键。
- 对方换头像后由增量同步更新缓存引用，不产生新联系人，也不要求手动维护。

## 5. 核心交互

- 联系人搜索、选择与当前状态可用。
- 联系人范围内搜索可打开。
- AI 建议支持确认和忽略；待办支持完成与恢复。
- 事实、需求和时间线事件可打开原文上下文。
- 同步状态须区分正常、可能滞后、未知分片、权限不足和版本不兼容。

## 6. 已完成的 UI 验收

- 1440 x 1024 浏览器截图与定稿图使用同一三栏比例和亮度。
- 左栏不呈现深色或灰蓝雾感；主区不出现大面积染色。
- 主要按钮、选中态和活动标签在白底上清晰明亮。
- 已测试联系人筛选、证据标签页、AI 确认、联系人范围内搜索和证据抽屉；控制台无错误。
